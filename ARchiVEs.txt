Pour documenter chaque étape de votre pipeline avec des sources officielles (théoriques) et expérimentales, voici une synthèse structurée. Chaque phase est accompagnée des références appropriées pour vous permettre de digitaliser les courbes et de respecter la physique sous-jacente.

---

## Phase 0 : Calibrations initiales

### Sources officielles (théoriques)

- **Norme ISO 5-3** (Status M) : définit les conditions de mesure densitométrique pour les films négatifs couleur.
- **Norme ISO 14524** : décrit la méthode de mesure de l'OECF (Opto-Electronic Conversion Function) et du bruit.
- **Jakob & Hanika 2019** : « A Practical Approach to Spectral Reconstruction » — cadre théorique pour la reconstruction spectrale à partir de valeurs RVB. PDF et code disponibles sur `https://rgl.epfl.ch/publications/Jakob2019Spectral`.

### Sources expérimentales

- **Jiang et al. 2013** : base de données de 28 caméras (400–720 nm, pas de 10 nm). Article PDF : `https://infosciences.epfl.ch/record/182538/files/egpaper_final.pdf`. Base de données : `https://zenodo.org/records/3245883`. ⚠️ L'échelle absolue est perdue, comme pour vos CSV.
- **Mitsuba-renderer/rgb2spec** : implémentation du modèle de Jakob-Hanika. `https://github.com/mitsuba-renderer/rgb2spec`.

## Phase 4 : Exposition du film (sensibilité spectrale)

### Sources officielles (théoriques)

- **Fiche E-4050, page 4** : courbes de sensibilité spectrale (couches jaune, magenta, cyan). Axe Y en log de 1/(erg/cm²). Lien : `https://www.fotomedia.ch/fm_fr/mwdownloads/download/link/id/850`.
- **Fiche Vision3 500T — 5219/7219** : courbes de sensibilité spectrale (TI2647D). `https://www.kodak.com/content/products-brochures/motion-picture/KODAK-VISION3-5219-7219-technical-information.pdf`.

- **Modèle de sensibilité spectrale** : équations données dans `https://dx.doi.org/10.2172/6677531`. Le document définit la sensibilité spectrale comme l'inverse de l'énergie requise pour atteindre une densité donnée.

### Sources expérimentales

- **Jiang et al. 2013** : base de données spectrale.

## Phase 5 : Grain et image latente

### Sources officielles (théoriques)

- **Newson, Faraj, Delon, Galerne (2017)** : « Realistic Film Grain Rendering » — modèle booléen basé sur la physique. PDF : `https://www.iopl.im/pub/art/2017/192/article.pdf`. Code : `https://www.iopl.im/pub/art/2017/192`.
- **Newson et al. (2017)** : « Analysis of a Physically Realistic Film Grain Model » — analyse théorique du modèle booléen, expressions pour l'espérance et la covariance. PDF : `https://hal.science/hal-01494123v2/file/film_grain_gaussian_texture.pdf`.
- **Zhang, Wang, Tian, Pappas (2023)** : « Film Grain Rendering and Parameter Estimation » — formules d'estimation des paramètres du modèle booléen à partir d'images scannées. PDF : `https://dl.acm.org/doi/pdf/10.1145/3592127`. DOI : `10.1145/3592127`.
- **Modèle booléen** : définition formelle. Le modèle booléen est un ensemble de boules dont les centres sont distribués selon un processus de Poisson d'intensité λ. Les boules représentent les cristaux d'halogénure d'argent.

### Sources expérimentales

- **PGI (Print Grain Index)** : fiche E-4050, page 3. Valeurs : 37 (4.4×), 59 (8.8×), 89 (17.8×) pour le format 135.
- **RMS Granularity** : mesure expérimentale par microdensitomètre. Méthodologie décrite dans `https://isprs.org/proceedings/XXIII/congress/part1/167_XXIII-B1.pdf`. L'ouverture standard est de 48 µm.
- **Valeur RMS du Portra 400** : une source mentionne RMS = 9, mais elle provient d'un forum et doit être vérifiée. La plage typique pour les films couleur est de 5 à 30.
- **Code open source** :
  - **Spektrafilm** : `https://github.com/andreavolpato/spektrafilm` — grain généré sur le négatif par modèle stochastique.
  - **filmr** (Rust) : `https://crates.io/crates/filmr` — simulation de grain basée sur RMS granularity et blur radius.
  - **Fotufilm engine** : `https://github.com/DhaliwalX/fotufilm-engine` — modèle d'exposition, développement et tirage.

## Phase 6 : Développement C-41 et effet d'interimage

### Sources officielles (théoriques)

- **Fiche technique Kodak Process C-41 — Z-131** : étapes, températures, réapprovisionnement. Lien : `https://business.kodakmoments.com/sites/default/files/wysiwyg/pro/chemistry/z131.pdf`.
- **Brevet US 6,274,299** : description détaillée des effets d'interimage, ratios de gamma (0,8 à 1,30), utilisation des coupleurs DIR. PDF : `https://patentimages.storage.googleapis.com/28/4b/2e/9710331272110b/US6274299.pdf`.
- **Brevet EP 0 905 561 A1** : méthode de détermination du facteur de diffusion d'un inhibiteur de développement. PDF : `https://patentimages.storage.googleapis.com/b3/30/68/d4ecd40f8b467d/EP0905561A1.pdf`. Le facteur de diffusion est calculé en comparant la réduction de densité entre un échantillon avec couche de Lippmann (piège à inhibiteur) et sans.
- **Brevet EP 0 505 008 A2** : évaluation de l'effet d'interimage par le rapport des gammas. Le rapport γ_couche4 / γ_couche2 est le critère. Plus le rapport est petit, plus l'effet d'interimage est faible.
- **Article J. Soc. Photogr. Sci. Technol. Japan** : revue sur la chimie des coupleurs DIR. Les inhibiteurs libérés diffusent horizontalement et verticalement dans l'émulsion, s'adsorbent sur les cristaux d'halogénure d'argent voisins et inhibent le développement.

### Sources expérimentales

- **Brevet US 5,447,819** : exemples de ratios de gammas mesurés (γ_vert/γ_rouge = 0,90 pour comparatif, 0,65 pour l'invention).
- **Brevet US 5,326,688** : tableaux de ratios d'accutance et de gamma.
- **Mesure du facteur de diffusion** : méthode expérimentale détaillée dans EP 0 905 561 A1. Le développement se fait dans le révélateur C-41 à 38°C pendant 120 s.
- **Cinétique de développement** : étude sur la pénétration des agents développateurs dans les couches de gélatine. La distance de pénétration est proportionnelle à la racine carrée du temps de développement.
