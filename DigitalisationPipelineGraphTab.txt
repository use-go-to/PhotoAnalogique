## 2.2 — agx-emulsion (Andrea Volpato)

**Dépôt principal :** `https://github.com/andreavolpato/agx-emulsion`
**Fil de discussion :** `https://discuss.pixls.us/t/spectral-film-simulations-from-scratch/48209`
**Statut :** Projet précurseur de Spektrafilm

### Structure des données

```
agx-emulsion/
└── agx_emulsion/
    └── data/
        └── film/
            └── negative/
                ├── kodak_portra_400/
                ├── kodak_ektar_100/
                ├── kodak_gold_200/
                ├── fujifilm_c200/
                ├── fujifilm_pro_400h/
                ├── fujifilm_xtra_400/
                └── kodak_vision3_50d/
```

### Fichiers par film

Même structure que Spektrafilm (`density_curve_*.csv`, `dye_density_*.csv`, `log_sensitivity_*.csv`, `info.txt`).

### Intérêt

- **Alternative** à Spektrafilm si un fichier manque.
- **Comparaison croisée** : si Spektrafilm et agx-emulsion donnent les mêmes courbes, c'est un gage de fiabilité.

### Installation rapide

```bash
git clone https://github.com/andreavolpato/agx-emulsion.git
cd agx-emulsion
ls agx_emulsion/data/film/negative/kodak_portra_400/
```

# 4. PLAN D'ACTION RECOMMANDÉ

## Phase A — Récupération des données existantes (1–2 h)

1. Cloner Spektrafilm et agx-emulsion
2. Copier les CSV Portra 400, Endura, Vision3 500T dans `data/digitalized/`
3. Vérifier la cohérence avec les PDF (tracer les courbes et comparer visuellement)

## Phase B — Digitalisation des courbes manquantes (3–4 h)

1. MTF Portra 400 (45 min)
2. MTF Vision3 500T (45 min)
3. RMS Vision3 500T (45 min)
4. Wratten 25, 99, 47B (60 min)

## Phase C — Recopie des tableaux (2 h)

1. Tableaux PGI + ancrage (E-4050)
2. Tableaux Endura (E-4070)
3. Tableaux procédés (Z-131, Z-130, CIS-269, Module 9A, H-24)

## Phase D — Calibration Canon 90D (2 h)

1. Prise de vue ColorChecker + flatfield + bruit
2. Calcul matrice + traitement

## Phase E — Intégration et validation (variable)

1. Intégration dans le pipeline Python
2. Validation contre un scan réel de Portra 400

**TOTAL ESTIMÉ : 8–10 heures** (au lieu de 20–25 h en digitalisant tout manuellement)
